# Alphado — Frontend

Next.js 16 + React 19 + Tailwind CSS v4 + Framer Motion frontend for **Alphado** (AI Voice Assistant & 24/7 Instagram Business Automation).

## Quick Start

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Production Build

```bash
npm run build
npm start
```

## Routes

- `/` — Alphado Landing Page (Light Mode default with full Dark Mode toggle)
- `/auth` — Email Sign-Up / Login, 6-Digit Verification Code, and Progressive Onboarding (Name, Business Name, Glowing Connect Instagram flow)
